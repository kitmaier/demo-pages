About this demonstration

This was inspired by a puzzle presented on the YouTube channel 3Blue1Brown.

The question raised in the video is what is the average number of intersections between a given number of randomly placed chords on a circle.

This page presents both a computer simulated answer, and one calculated exactly.

The simulation

The code of the simulation is visible in the page source. It randomly generates a pair of numbers between 0 and 1 for each chord, representing how far around the circle each end of the chord is placed, and then checks whether the ranges represented by these pairs of numbers overlap. The total number of intersections between chords across all iterations of the simulation, divided by the number of iterations, is the displayed average value.

Geometry is not needed at this point, and is only required in order to display an example diagram of randomly generated chords with intersections. All that matters to determine whether two chords intersect, is whether their endpoints are in alternating order around the circle.

The calculation

The simplest case is when there are only two chords, as there can be at most one intersection.

Suppose that one chord has already been placed, more or less vertically, and we want to know the probability that the other chord will intersect it.

The probability that one endpoint of the new chord will be on the left of the first chord is the proportion of the circle on that side, and the probability that the second endpoint will be on the right is the proportion of the circle on the right, so the probability that both will happen at once is the product of those two proportions. Because the endpoints could be reversed, the total probability of an intersection is double that.

Let the first endpoint of the first chord be selected, and then how far around the circle from there the second endpoint is can be the value X ranging from 0 to 1.

For each value of X, the probability of the second chord creating an intersection is 2*X*(1-X) = 2X-2X^2.

We can find the overall probability of intersection by evaluating the integral [X^2-(2/3)X^3] between 0 and 1, which results in 1-(2/3) = 1/3

Once we have found that the probability of two chords intersecting is 1/3, the step to a larger number of chords is surprisingly easy.

Because we are only looking for the expected value of the number of intersections, which is the average number of intersections over a large number of randomly selected samples, it doesn't matter whether those intersections happen at the same time or not.

For each pair of chords, we only care about the average number of times they will intersect, independent of all other pairs of chords, which is 1/3 of the time.

The number of pairs of chords is a triangular number, so for N chords we can use the formula that there are N(N-1)/2 pairs of chords.

Multiplying these together, the average number of intersections of N randomly placed chords is expected to be N(N-1)/6 chords, which is the number displayed, and which agrees closely with the simulated result.
